# Project Approach

This project was developed to explore dam risk using geospatial analysis and interactive data visualization in Tableau.

## Data Preparation

- Connected multiple datasets containing dam and population information.
- Performed a spatial join between dam locations and nearby population data.
- Extracted the combined dataset for analysis.

## Geospatial Analysis

- Created a configurable buffer distance parameter to analyze surrounding areas.
- Calculated the distance between dam locations and nearby population centers.
- Filtered records dynamically based on the selected buffer distance.
- Built interactive geospatial maps to visualize dam locations and affected areas.

## Dashboard Development

Designed an interactive dashboard featuring:

- Risk Radius map
- Population Distribution map
- Interactive filters for:
  - Area
  - State
  - County
  - Hazard Classification
  - Dam Type
  - Dam Name
- Adjustable buffer distance parameter
- Detailed dam information table

## Visualization Design

- Applied custom map layers and color palettes to distinguish hazard levels.
- Used floating containers and responsive dashboard layout for improved usability.
- Organized filters and visual components to support intuitive exploration.

## Business Outcome

The final dashboard enables users to:

- Explore dam locations across different regions.
- Identify higher-risk dams.
- Analyze nearby population exposure.
- Investigate dam characteristics through interactive filtering.
- Support infrastructure risk assessment using geospatial visualization.
